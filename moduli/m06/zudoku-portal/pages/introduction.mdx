# Checkout API

This portal combines two kinds of content:

- **Guides**, written by hand in MDX files under `pages/`: authentication, errors and retries.
- **API reference**, generated from the OpenAPI contract of the checkout case (`/api`), with named examples and a request playground.

The reference is built from the contract file, not from the code. It describes payments, orders and shipment tracking. The examples are fixtures for the mock server and do not describe real transactions.

Start with [Errors and retries](/errors-and-retries), then open the [API reference](/api).
